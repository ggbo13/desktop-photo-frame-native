# preview.17 缩放绘制核验

日期：2026-10-27。Windows x64，原生版本 2.0.0-preview.17。

## 修复内容

设置窗口旧布局每次先隐藏整页控件再逐个显示。preview.16 的隔离对照测试记录到 2548 次子控件隐藏事件。新版只在页面或可见范围改变时切换显隐，按 HWND 保留最后目标，批量应用变化的几何和裁剪，随后统一提交绘制。文字标签和自绘预览在内存中完整绘制后一次复制，保留标签实际字号，并排除预览的所有者绘制类型。选中状态改变时单独刷新导航、固定角和视图按钮。

大图旧实现让 Direct2D 与原生按钮共用顶层窗口，采集到 9 帧按钮区域缺失。新版把照片绑定到独立子画布，父窗口排除子控件区域；尺寸变化后在当前消息内补绘。这样也避免等待空闲消息才刷新照片。[Direct2D Resize 文档](https://learn.microsoft.com/en-us/windows/win32/direct2d/id2d1hwndrendertarget-resize)说明，尺寸变化后缓冲内容无定义，不能依靠保留内容选项替代重绘。

## 验证方法与边界

`resize-paint-smoke.ps1` 只采集被测窗口的 Windows Graphics Capture 帧，使用系统时间戳，检查网格照片、文字/按钮和相框预览区域的像素。固定标题、导航、照片区不能反复隐藏；底部参数随高度收起单独计数。窗口连续改变大小，未完成的尺寸请求不堆积。可加 `-RecordVideo` 保存录像；默认只保存统计和少量帧。

该检查能捕捉本次按钮消失和整页反复隐藏，但不代表逐像素检查了所有界面、所有显卡或给出了硬件掉帧率。1368 次尺寸矩阵中的 100%/125%/150% 是布局比例模拟；过大的输入按工作区收缩并记录实际尺寸，未切换真实系统 DPI。
