# preview.19 验证记录

设置窗口开始拖动尺寸时，将当前窗口内容临时保存在内存；拖动期间按原像素大小显示，超出原区域时留白，缩小时裁切，松开后恢复原有双缓冲和完整布局。缓存创建失败时回退到原有布局；单张缓存限制在 1600 万像素以内。滚动条使用 Windows 原生绘制，避免系统与应用覆盖式绘制交替闪烁。

真实鼠标验证由用户操作，使用独立测试实例和四张合成图片，不创建托盘图标、不截图、不录屏，用户反馈“流畅，画面正常”。具体体验及桌面负载随硬件和窗口内容而异；拖动时临时画面不会实时重排，松开后恢复。

最终版本通过低负载模拟缩放生命周期检查，确认结束后缓存窗口销毁、窗口样式恢复；28 项设置布局与排序、35 项设置及主题、13 项托盘命令、6 项设置交互和 19 项大图画布交互通过；新版安装包在独立目录安装、启动通过。测试不运行持续画面采集或压力测试，没有新增测试托盘记录。

没有进行不同系统 DPI、跨屏、多显示器的实际拖动检查，未测量物理屏幕帧率、长期稳定性或 GPU 内存。缓存方案可能在极大窗口或资源不足时退回旧的布局方式。手动反馈只针对本次使用的测试机与场景，不能保证其他场景完全无闪烁。
