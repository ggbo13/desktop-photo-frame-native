# preview.18 验证记录

设置页面缓存固定控件的层级顺序，集合或顺序变化时重新排列；其他尺寸变化保留原顺序。保持原双缓冲与同步重绘，不更改播放或用户配置。

在本机 125% DPI、照片页、24 张合成图、模拟 30 Hz 尺寸变化的三轮交错对照中，窗口合成尺寸变化间隔的中位数从 48.604 ms 降到 34.718 ms，P95 从 76.380 ms 降到 55.552 ms；过时目标合并率从 34.67% 降到 12.67%。这些数据来自 Windows Graphics Capture 窗口帧，不代表实际屏幕帧率，也不能保证其他机器同样提升；SetWindowPos 和模拟缩放消息不能完整代替鼠标拖拽。

最终构建通过设置和大图的画面像素检查；复测模拟缩放时，文字、照片和相框预览丢失帧均为零。一次补充采集发生等待超时，复测通过，原因尚未确认。布局排序 28 项、设置主题 35 项、大图画布 19 项及托盘命令 13 项通过。隔离安装新版成功。全部测试没有新增托盘历史。

常规回归中的托盘命令起初因为测试仍期望旧版本号而失败；修正测试后该项单独重跑通过。安装测试也在更新默认路径后重新运行新版并通过。真实鼠标持续拖动、其他实际 DPI、跨屏和物理显示器帧率未在本次完成验证。
