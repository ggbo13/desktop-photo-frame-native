# preview.16 设置缩放修复核验

日期：2026-10-27。Windows x64，最终版本 2.0.0-preview.16。

## 根因与修复

preview.15 的设置窗口在约 1000×720、100% 布局比例下稳定停止响应。诊断记录显示客户区宽度在 982 与 961 像素之间交替：预览显示后需要滚动条，滚动条挤窄内容后又隐藏预览，继而隐藏滚动条，反复递归重排。主线程无法正常重绘，符合用户同时观察到的鼠标残影现象。

修复保留纵向滚动条占位，内容不足时禁用滚动；将无界递归改为最多三次重排，并保持整个过程防重入，最后恢复焦点。未改变照片文件或用户配置结构。

完整矩阵按显示器工作区限制过大的输入，同时记录请求和实际尺寸；不会把被 Windows 拒绝的目标尺寸算作成功。100%/125%/150% 是应用布局比例模拟，不代表切换了真实系统 DPI。截图检查设置重绘，不等于长时鼠标轨迹录像或所有显示驱动情况的验证。

空闲相框仍为 281×402 的局部画布；采样期间无重复合成提交或相框重绘，可见约 4 次/秒、隐藏约 1 次/秒唤醒。本轮未重新进行长期内存、硬件呈现掉帧及跨屏目视验收。
