# 原生照片库与夜间模式

preview.15 使用 Win32 / GDI 绘制设置界面，继续使用 Direct2D / DirectComposition 播放照片；没有加入浏览器内核或常驻界面动画。

- 宽窗口使用侧栏导航、播放列表、照片主区和固定预览，照片操作留在底部。外观页的大预览与参数分别安排，滚动不带走预览。
- 窄窗口改用顶部导航与列表下拉框，压缩重复信息；最小窗口会缩小固定预览，为外观参数保留可用区域。
- 左下角按钮或“应用 → 界面主题”切换浅色/夜间。主题是全局设置，重启后保留，不改变每个列表的相框颜色或 Windows 配色。
- 单击照片改变选中预览，双击或“播放”才改变轮播。Ctrl/Shift、键盘焦点和拖动排序继续可用。
- 木纹沿四边延伸并形成斜接，金属拉丝更细，拍立得使用中性纸白；外沿高光与内圆角保持克制。四边仍等宽，无边框保持零边框。
- 缩略图与预览的像素缓存总上限为 8 MiB。较高分辨率优先给预览，其他缩略图按可见数量分配；不再作为大预览的图片可降低缓存分辨率，关闭设置释放缓存。

旧布局与绘制方法仍保留。新增 `global.theme` 自动补默认值，未知配置字段及备份保留。测试接口仅在 `--test-hooks` 下启用；键盘验证只修改窗口线程状态并恢复，不向桌面注入按键。
